# Project Docs

Welcome to the documentation for the Auto Shift Scheduler project. This folder explains architecture, feature organization, coding conventions and contains line-by-line explanations of representative hooks, services, types and utils used across the app.

Top-level docs:
- ARCHITECTURE.md — Big picture, design principles, RBAC, and data flow
- FEATURES.md — Feature-based organization and per-feature responsibilities
- CODE_GUIDE.md — Deep-dive with line-by-line explanations and examples for hooks, services, types and utils

If you want a quick start, read `ARCHITECTURE.md` then `CODE_GUIDE.md`.
